# Digital Clock

A simple digital clock that displays your local time in the browser and updates every second.

## Features

- Displays the current local time.
- Automatically updates every second.
- Minimal dark theme with centered clock text.
- No external libraries or dependencies required.

## How to Run

1. Download or clone this project folder.
2. Open `index.html` in your browser.

Alternatively, open the folder in VS Code and run `index.html` using the **Live Server** extension.

## Project Files

- `index.html` — The clock page and links to the JavaScript and CSS files.
- `style.css` — The clock's layout and styling.
- `first.js` — Displays the current time and updates it every second.
